## 晚上（真实邮件联通）

### 目标

用真实 163 邮箱（SMTP SSL）验证「最基本的邮件提醒」，收件人 pky1999@qq.com、pkyit@qq.com。

### 过程与发现

1. 先写临时 Java 程序直接调用 `EmailChannel.send`（凭据走环境变量，临时目录，不入库）。
2. 第一次发送失败：`ChannelAuthException: SMTP authentication failed`（两个收件人都失败）。
3. 用 Python `smtplib.SMTP_SSL('smtp.163.com', 465).login(...)` 验证：`235 Authentication successful`
   → 凭据与网络没问题，问题在 SDK。
4. 定位：`EmailChannel` 只设置了 `mail.smtp.auth=true`，但 `Session` 没有 `Authenticator`；
   `Transport.send(message)` 不传用户名/密码，JavaMail 根本不会提交凭据 → 服务器回 535。
5. 修复：`Session.getInstance(props, authenticator(properties))`，有用户名时提供
   `PasswordAuthentication(username, password)`；无用户名保持匿名中继。
6. 补 2 个回归测试（有/无用户名时 `requestPasswordAuthentication` 的结果）。
